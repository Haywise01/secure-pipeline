# Exercise 1.2: Security Scanning & SAST Gates

## Overview
This module automates code security analysis to catch vulnerabilities and leaked credentials early in the development lifecycle.

## Implemented Tools
1. **Semgrep**: Scans source code using automated rulesets to catch application logic flaws and security anti-patterns.
2. **Gitleaks**: Scans git commit history for sensitive information, API tokens, and passwords to prevent credential leakage.
